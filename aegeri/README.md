# Aegeri
A toy programmable transaction system built with [`fuste`](https://github.com/ramate-io/fuste).

## Getting Started 

To get started, watch the [demo](https://www.loom.com/share/74b94bcd905b41babf65b4bcf88c4093):

- [Running a local cluster](https://www.loom.com/share/74b94bcd905b41babf65b4bcf88c4093?t=214)
- [A rant about bootstrapping](https://www.loom.com/share/74b94bcd905b41babf65b4bcf88c4093?t=330)
- [Breaking consensus with lazy participants](https://www.loom.com/share/74b94bcd905b41babf65b4bcf88c4093?t=452)
- [Sending `fuste` programs to the network](https://www.loom.com/share/74b94bcd905b41babf65b4bcf88c4093?t=580)
- [A rant about `gwrdfa` API design](https://www.loom.com/share/74b94bcd905b41babf65b4bcf88c4093?t=720)

Once you've watched the demo, you can work with Aegeri via the [CLI](./cli/docs/cli/README.md).
